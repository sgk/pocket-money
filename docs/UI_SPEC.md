# UI仕様書（開発用）

この文書は、UIの見た目と挙動の「重要な仕様」をまとめたものです。実装時に迷う点を減らし、画面ごとの一貫性を保つために使います。

## 共通ルール

- 画面は `AppLayout` 配下で表示され、上部にヘッダー、左にサイドバー、右側にメイン領域がある。
- 各画面の先頭には `Topbar` を置く。タイトルとサブタイトルを基本とし、必要なら補助UI（元帳のフィルタなど）を入れる。
- 画面の縦スクロールは「メイン領域側で行う」。親レイアウトは `overflow-hidden` なので、スクロール可能なコンテナを必ず用意する。
- ドラッグ＆ドロップは「行全体で開始できる」ことを前提にする。ただし入力欄・ボタン等はドラッグ開始を抑止する。

## 編集の共通ルール（設定画面）

- 一度に編集できるのは **1行のみ**。
- 行をクリックすると編集モードに入る。
- 編集中は ✓ / ✕ / 🗑️ を表示する。順番は **✓ → ✕ → 🗑️**。
- 画面内でフォーカスがどこにあっても Esc でキャンセルできる。
- 編集中のドラッグは無効にする。
- 編集前は「表示のみ」。入力欄は表示しない。
- 無効状態の行は編集前だけ薄い色で表示する。

## 画面一覧

### ログイン

- パス: `/login`
- Googleログインボタンを表示する。
- ログイン処理中は文言を表示する。
- 失敗時はエラーメッセージを表示する。

### 年齢確認

- パス: `/`（未同意時はオンボーディング画面を表示）
- 2画面構成（URLは同一）。
  - 第1画面: データのエクスポート（JSON/CSV）と「進む」ボタンを表示する。
  - 第2画面: 年齢選択・利用許諾条件同意（18歳以上）・招待した親のGoogleアカウント入力（18歳未満）を表示する。

### まとめ

- パス: `/`
- 資産のカード一覧（合計・各資産）を表示する。
- 月次の収入/支出/残高カードを表示する。
- 最近の取引（最大10件）を表示する。

### ぜんぶ元帳

- パス: `/ledger`
- `Topbar` に期間・検索・並び順のフィルタを表示する。
- テーブル表示は日付グループを含む。
- 新規行入力は常に表示される。
- 編集中は新規行入力を無効にする。
- 編集は行単位。✓/✕/🗑️で確定・取消・削除を行う。
- 行のドラッグで並び替えができる。
- 画面下部にサマリーバーを固定表示する。

### いれもの一覧

- パス: `/assets`
- 資産カード一覧を表示する。
- カードを押すと該当の資産元帳に遷移する。

### いれもの元帳

- パス: `/assets/:assetId/ledger`
- 元帳の仕様は「ぜんぶ元帳」と同様。
- 対象資産の取引のみを表示する。
- `Topbar` には資産名と現在残高を表示する。

### いれもの設定

- パス: `/settings/assets`
- 新規資産の追加フォームを表示する。
- 資産一覧はドラッグで並び替えできる。
- 行をクリックすると編集モード。
- 編集中の行ではチェックボックスが **編集ボタンの前** にある。
- 編集中は「いまののこり」欄に ✓/✕/🗑️ を表示する。
- 編集前は「いまののこり」金額をリンク表示する。
- 金額リンクは常時アンダーライン、色はブラウザ標準。
- 非編集時は「ゆうこう/むこう」の表示は行わない。

### うごき設定

- パス: `/settings/categories`
- 「だした」「いれた」の2セクションを持つ。
- `その他` は固定カテゴリとして編集対象から除外する。
- 行をクリックすると編集モード。
- 編集中の行ではチェックボックスが **編集ボタンの前** にある。
- 編集中は ✓/✕/🗑️ を表示する。
- 非編集時は「ゆうこう/むこう」の表示は行わない。
- ドラッグで並び替え、他セクションへの移動も可能。

### データ管理

- パス: `/settings/data`
- JSON/CSVエクスポートを提供する。
- JSON/CSVインポートを提供する。
- 全データ削除、退会を提供する。
- 破壊的操作は必ず確認ダイアログを出す。

### 設定

- パス: `/settings`
- 学年設定を変更できる。
- 親/子の状態に応じて表示が変わる。
  - 親: 子の招待カード・利用許諾条件リンク・危険な操作を表示する。
  - 子: 保護者情報カードと「招待を確認する」（親アカウント入力）を表示する。利用許諾条件リンクは表示しない。
  - 親が子を表示中に子設定画面の「招待を確認する」を押した場合、確認対象は親本人ではなく表示中の子になる（`C→B` を確認する）。
- 子の招待
  - Googleアカウント入力欄の右に「招待を作成する」ボタンを置く。
  - 招待済み人数は「招待済みの子」行の右端に表示する。
  - 招待キャンセルはゴミ箱アイコンで行う。
  - 利用開始済みの子は、メールアドレスの後ろに子の名前を表示する。
  - 子が「招待を確認する」に成功した直後は、「確認済みの保護者」を即時更新する。
  - 利用開始済みの子の招待削除に成功した直後は、アカウントアイコンメニューの子候補を即時更新する。
  - すでに切断された子を `childId` で表示中だった場合は、親をログアウトさせず、自分表示へ戻す。

### 利用許諾条件

- パス: `/settings/terms`
- 親のみアクセス可能。子は直接アクセスしても設定画面へリダイレクトされる。
- 新しい版がある場合のみ表示し、同意を促す。
- 同意済みの利用許諾条件を表示する。
- 「同意をとりやめる」ボタンで即ログアウトする。

## 画面別の入力/保存の原則

- 入力欄で Enter は保存に相当する。
- Esc はキャンセルに相当する。
- 保存後は表示モードに戻る。

## 取引・資産・うごきの参照ルール（ID＋名前）

- 取引は **IDを主キー** にして資産・うごきを参照する。
- 取引には **名前スナップショット** も保存し、表示や復旧に使う。
- 取引には **支出/収入の別** を持つ（`type` の `expense/income` を流用）。
- 集計・検索・並び替えは **IDが有効であればID基準** で行う。

### 参照が欠落している場合

- 参照先が存在しないことに気づいたときは **自動作成する**。
- ただし自動作成は **保存・編集・並べ替えなど書き込み時のみ** 行う。
  - 閲覧のみで勝手に増えることは避ける。

### リネームと同名の扱い

- IDが有効な場合は最新の名称を表示する。
- 表示の矛盾に気づいたら修正する（名前スナップショットの更新）。
- 同名は不可。編集時に衝突する場合は **訂正 or マージ** を選ばせる。

### インポート時の解決ルール

- 名前の照合は **厳密一致のみ**。
- 一致しない場合は **自動作成**。
- 自動作成の初期値
  - `isActive`: true
  - `kind`/`type`: 取引側の `expense/income`
  - `memo`: 空
  - `initialBalance`: 0
  - `sortOrder`: 末尾に追加
## ドラッグ＆ドロップの原則

- ドラッグ開始は行全体で可能。
- 入力欄・ボタン・リンク上ではドラッグ開始しない。
- 並び替え完了後は即時に順序を保存する。
